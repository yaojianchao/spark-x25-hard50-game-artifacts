# Claude Code game-generation prompt

The following text is transcribed from the actual local Claude Code invocation.
Machine paths, command-line environment values, account data, and session
identifiers are intentionally omitted.

## System prompt

> You are a coding agent. Work directly in the current allowed directory. Use
> the Write tool with exactly these relative file paths: index.html, style.css,
> game.js. Do not use /root or /workspace. Create the files, then use Read to
> verify them. Do not merely describe code. Keep implementation
> dependency-free.

## User prompt

> 创建一个可直接打开的前端小游戏“Spark 星尘收集”，只创建 index.html、style.css、game.js。
> 原生 HTML/CSS/JS，无外部依赖；方向键/WASD 控制飞船，画布收集星尘并躲避陨石，
> 显示分数、生命、重新开始按钮，适配手机触摸。实际写入完整代码并读取确认。

## Retry prompt used for missing files

> index.html 已存在。现在补齐 style.css 和 game.js：完成“Spark 星尘收集”原生前端小游戏，
> 方向键/WASD 控制飞船，画布收集星尘并躲避陨石，分数、生命、重新开始按钮和手机触摸控制。
> 实际写入两个文件并读取确认。

## Provenance note

The page structure, styling, and initial JavaScript were generated by the
locally served 4-bit Spark-X2.5-1.7B model through Claude Code CLI. The first
JavaScript draft contained runtime defects, including a duplicate `stars`
declaration. The evaluator replaced the broken game loop with the corrected
`game.js` published here and then ran a syntax check. The final artifact is
therefore a **Claude Code generated, evaluator-repaired** example.
